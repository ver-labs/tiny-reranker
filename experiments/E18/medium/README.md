# Article formats and images

The [article source](../ARTICLE_DRAFT.md) describes all 13 experiment groups
from E18-small-v1. The authoritative evidence is in the
[report](../REPORT.md), [results](../RESULTS.md), and [frozen protocol](../plan.json).

- [AsciiDoc source](ARTICLE.adoc) preserves editable native tables.
- [Rendered AsciiDoc HTML](ARTICLE_ASCIIDOC.html) displays selectable table text.
- [Medium copy HTML](ARTICLE_MEDIUM.html) displays tables as PNGs; download and
  open it locally with the `tables/` folder beside it.
- [Numbered upload images](upload_images/) contains 16 table images and five plots
  in article order. [UPLOAD_ORDER.txt](upload_images/UPLOAD_ORDER.txt) maps each
  filename to its placeholder.
- [Upload ZIP](medium_upload_images.zip) bundles those 21 images and the guide.

Medium may not preserve HTML tables or local images during paste. Upload the
numbered PNGs individually at their matching positions. Add image descriptions
and public repository links before publishing. The images contain measured
results; copying a table as an image does not make its text accessible to screen readers.
